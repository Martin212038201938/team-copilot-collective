# Zertifizierungs-Logo-Kacheln

Ziel: Pro Anbieter eine Kachel (rund oder quadratisch) mit dem offiziellen Anbieter-Logo
und dem Zertifikatsnamen darunter, als Trust-Signal für die Website.

## Ablauf
1. Offizielles Logo des Anbieters besorgen (Presse-/Brand-Seite, siehe unten).
2. Datei unter dem angegebenen Dateinamen in diesen Ordner legen (PNG mit transparentem
   oder weißem Hintergrund, möglichst quadratisch, mind. 400 px).
3. Bescheid geben — die fertigen Kacheln (Logo + Name darunter) werden dann gebaut.

Vorlagen: muster_rund.png / muster_quadrat.png zeigen das Zielformat.

## Hinweis Nutzungsrechte
Vor Veröffentlichung je Anbieter die Logo-Nutzungsbedingungen prüfen. Die Nennung neben dem
echten Zertifikatsnamen ist zulässige Nennung; manche Anbieter verlangen dennoch Freigabe.
